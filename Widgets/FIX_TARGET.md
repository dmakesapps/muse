# How to Fix Widget Extension Target

## Step 1: Delete the Old Widget Extension Target

1. In Xcode, select the **MuseWidgets** target in the project navigator (left sidebar)
2. Right-click on the **MuseWidgets** target
3. Select **Delete**
4. Choose **Move to Trash** (not just Remove Reference)

## Step 2: Delete the Widget Extension Folder

1. In Finder, navigate to your project folder
2. Find and delete the `MuseWidgets` folder (if it exists)
3. This folder was auto-generated by Xcode

## Step 3: Create New Widget Extension Target

1. In Xcode, go to **File > New > Target...**
2. Select **Widget Extension** under iOS
3. Click **Next**
4. Configure:
   - **Product Name**: `MuseWidgets`
   - **Team**: (your team)
   - **Organization Identifier**: `Ephesian28LLC`
   - **Bundle Identifier**: `Ephesian28LLC.Muse.MuseWidgets`
   - ✅ **CHECK** "Include Configuration Intent" ← IMPORTANT!
5. Click **Finish**
6. When prompted, click **Activate** to activate the scheme

## Step 4: Configure App Groups (Again)

### For Main App Target:
1. Select the **Muse** target
2. Go to **Signing & Capabilities** tab
3. If App Groups isn't there, click **+ Capability** and add **App Groups**
4. Make sure `group.Ephesian28LLC.Muse` is checked

### For New Widget Extension Target:
1. Select the **MuseWidgets** target
2. Go to **Signing & Capabilities** tab
3. Click **+ Capability**
4. Add **App Groups**
5. Add: `group.Ephesian28LLC.Muse`
6. Make sure it's checked

## Step 5: Delete Auto-Generated Files

Xcode will have created some default widget files. Delete these:
- `MuseWidgets/MuseWidgets.swift` (or similar auto-generated file)
- `MuseWidgets/MuseWidgetsBundle.swift` (if exists)

## Step 6: Add Our Widget Files to the Target

1. Select each of these files in the project navigator
2. In the **File Inspector** (right panel), under **Target Membership**
3. Check the **MuseWidgets** target for:
   - `Widgets/MuseWidget.swift`
   - `Widgets/QuoteWidget/QuoteWidget.swift`
   - `Widgets/QuoteWidget/QuoteWidgetConfigurable.swift`
   - `Widgets/AffirmationWidget/AffirmationWidget.swift`
   - `Widgets/AffirmationWidget/AffirmationWidgetConfigurable.swift`
   - `Widgets/Shared/SharedDataService.swift`
   - `Widgets/Shared/Models.swift`
   - `Widgets/Shared/Color+Hex.swift`

## Step 7: Update the Widget Bundle Entry Point

The `MuseWidget.swift` file should be the main entry point. Make sure it's set as the widget bundle.

## Step 8: Build and Test

1. Build the project (⌘B)
2. Make sure there are no errors
3. Run the app and test the widgets!
